НУЖНО ДЛЯ ЗАПУСКА:
1) Создать в Pella: CREATE -> Telegram Bot -> NodeJS -> File Upload.
2) Загрузить этот ZIP.
3) Pella должна распаковать index.js и package.json в корень проекта.
4) Указать Telegram Bot Token в переменной:
   TELEGRAM_BOT_TOKEN
   Код также понимает BOT_TOKEN или TOKEN.
5) Telegram user id уже встроен: 505975862.
6) Команда запуска: npm start
7) В Telegram:
   /start
   /status
   /test
   /check
   /reset

ВАЖНО:
- При первом запуске бот запоминает текущие балансы и НЕ отправляет уведомления о старых средствах.
- После нового поступления отправит кнопку автоматически.
- Для нативных монет из суммы делается небольшой резерв под комиссию. Trust Wallet всё равно окончательно проверяет сеть/fee.
- Для USDT TRC-20 сумма поступления подставляется полностью; для отправки на TRON потребуется TRX/energy по правилам сети.
- Если публичный RPC временно недоступен, /status покажет ошибку конкретной сети.
